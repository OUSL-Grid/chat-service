# chat-service
OUSL GRID

## GitHub project bootstrap script

This repository includes a helper script to create a milestone and a starter issue set for the Campus Marketplace MVP (chat, listings, moderation, and auth scope).

```bash
./scripts.sh --owner OUSL-Grid --repo chat-service
```

Optional flags:

- `--milestone "Campus Marketplace MVP"`
- `--due-on "2026-12-31T23:59:59Z"`
- `--dry-run`
